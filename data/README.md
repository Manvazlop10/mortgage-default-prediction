# Data

The notebook expects two course-provided files in this folder:

- `mortgagedefault.csv`: about 300 labeled records
- `mortgage_prediction.csv`: 20 unlabeled applicants to score

Columns: `Age`, `Marital Status`, `Annual Income ($)`, `Mortgage Amount ($)`, `Total Amount Paid ($)`, and the target `Default on Mortgage?` (YES/NO). All features are used as numeric inputs.

The files were provided for a university course and are not redistributed here.
